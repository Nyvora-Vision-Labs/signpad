# Examples

| File | What it shows |
|---|---|
| `try_the_agent.sh` | Makes sample forms and runs the agent on one with `request_email.txt` |
| `request_email.txt` | The kind of request SignPad is built for: "re-sign with a handwritten signature" |
| `sign_without_agent.py` | The Python API: pick a slot yourself, draw in the pad, save |

`signpad samples demo/` writes `sample_agreement.docx` (text boxes, a table, an underscore line), `sample_consent.pdf` (a label, underscore lines, a form field) and `sample_signature.png`.
